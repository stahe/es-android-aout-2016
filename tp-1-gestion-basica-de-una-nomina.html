    4. TP 1: Gestión básica de una nómina

    4.1. Introducción

    Para aplicar lo visto anteriormente, proponemos ahora un trabajo que consiste en escribir un cliente Android para tableta, que permita simular los cálculos de las nóminas de los empleados de una asociación.

    La aplicación tendrá una arquitectura cliente/servidor:

    • el servidor [1] ya está disponible;
    • hay que compilar el cliente Android [2].

    4.2. La base de datos

    4.2.1. Definición

    Los datos estáticos necesarios para crear la nómina se almacenarán en una base de datos a la que en adelante nos referiremos como «dbpam» . Esta base de datos contiene las siguientes tablas:

    Tabla EMPLOYES: recopila información sobre las diferentes cuidadoras infantiles

    Estructura:

    ID
    clave primaria
    VERSION
    n.º de version – aumenta con cada modificación de la línea
    SS
    Número de la Seguridad Social del empleado: único
    NOM
    apellido del empleado
    PRENOM
    su nombre
    ADRESSE
    su dirección
    VILLE
    su ciudad
    CODEPOSTAL
    su código postal
    INDEMNITE_ID
    clave externa en el campo [ID] de la tabla [INDEMNITES]

    Su contenido podría ser el siguiente:

    Tabla COTISATIONS: recopila los porcentajes necesarios para el cálculo de las cotizaciones sociales cotisations

    Estructura:

    ID
    clave primaria
    VERSION
    N.º de version – aumenta con cada modificación de la línea
    CSGRDS
    porcentaje: contribución social generalizada + contribución al reembolso de la deuda social
    CSGD
    porcentaje: contribución social generalizada deducible
    SECU
    porcentaje: seguridad social, viudedad, vejez
    RETRAITE
    porcentaje: pensión complementaria + seguro de desempleo

    Su contenido podría ser el siguiente:

    Las tasas de las cotizaciones sociales son independientes del empleado. La tabla anterior solo tiene una línea.

    Tabla INDEMNITES: reúne los elementos que permiten calcular el salario a pagar.
    ID
    clave primaria
    VERSION
    n.º de version – aumenta con cada modificación de la línea
    INDICE
    Índice de procesamiento - único
    BASEHEURE
    Precio net en euros por una hora de guardia
    ENTRETIENJOUR
    indemnización de manutención en euros por día de cuidado
    REPASJOUR
    indemnización por comida en euros por día de servicio
    INDEMNITESCP
    Indemnización por vacaciones pagadas. Se trata de un porcentaje que se aplica al salario base.

    Su contenido podría ser el siguiente:

    Cabe señalar que las indemnizaciones pueden variar de una cuidadora a otra. De hecho, están asociadas a una cuidadora concreta a través de su índice salarial. Así, la Sra. Marie Jouveinal, que tiene un índice salarial de 2 (tabla EMPLOYES), tiene un salario por hora de 2,1 euros (tabla INDEMNITES).

    4.3. Instalación del servidor web / jSON

    4.3.1. Instalación

    Se le proporciona el binario Java del servidor web / jSON:

    Para iniciar el servidor web / jSON, proceda de la siguiente manera:

    • ejecute el SGBD MySQL;
    • asegúrese de que BD [dbpam_hibernate] existe;
    • abra una ventana DOS;
    • vaya a la carpeta de jar;
    • escriba el comando: 
    java -jar pam-server-01-all-1.0.jar

    Esto supone que el binario [java.exe] se encuentra en el directorio PATH de su equipo. Si no es así, escriba la ruta completa de [java.exe], por ejemplo:

    D:\Programs\devjava\java\jdk1.8\bin\java -jar pam-server-01-all-1.0.jar

    4.3.3. Las respuestas jSON del servicio web/jSON

package client.android.dao.service;
 
import java.util.List;
 
public class Response<T> {
 
    // ----------------- propiedades
    // estado de funcionamiento
    private int status;
    // cualquier mensaje de estado
    private List<String> messages;
    // el cuerpo de la respuesta
    private T body;
 
    // fabricantes
    public Response() {
 
    }
 
    public Response(int status, List<String> messages, T body) {
        this.status = status;
        this.messages = messages;
        this.body = body;
    }
 
    // getters y setters
...
}

    4.4. Pruebas del cliente Android

    Se le proporciona el binario ejecutable del cliente Android terminado:

    Arrastra con el ratón el binario [pam-client.apk] que aparece arriba hasta un emulador de tableta [GenyMotion]. Se guardará y se ejecutará. Inicia también el servidor web / jSON si aún no lo has hecho. El objetivo del cliente Android es recuperar la información enviada por el servidor web / jSON y darle formato. Las diferentes vistas del cliente Android son las siguientes:

    En primer lugar, hay que conectarse al servicio web / jSON:

Con una tableta, introduzca la dirección wifi del equipo del servidor web / jSON y desactive el cortafuegos del servidor si lo tiene, ya que podría bloquear las llamadas entrantes;
    • En [2], nos conectamos;

    A continuación, se accede a la página de simulación:

    • en [3], se elige un empleado;

    4.5. Tareas pendientes

    Se te proporciona el esqueleto del cliente para Android presentado anteriormente. Se ha creado a partir del proyecto [client-android-skel] descrito en el apartado 2 .

    El proyecto es ejecutable y ya cuenta con las vistas necesarias. Solo hay que añadir código para que la aplicación haga lo que tiene que hacer. El procedimiento a seguir es el siguiente:

    • ejecute el version completo para comprender el trabajo que hay que realizar;
    • ejecute el version simplificado y estudie su código. Este respeta los métodos de diseño utilizados en las páginas anteriores;
    • añada el código que falta;
