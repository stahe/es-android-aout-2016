## 📖 Resumen

Este documento es una reescritura y consolidación de varios recursos educativos sobre desarrollo para Android. Su objetivo es proporcionar una **introducción gradual y estructurada** a la programación de aplicaciones para Android, especialmente para tabletas.

Incorpora varios avances importantes:

* Adopción de **Android Studio** como entorno de desarrollo principal
* Uso del sistema de compilación **Gradle**
* Introducción de **RxJava** para gestionar operaciones asíncronas
* Estructuración avanzada de aplicaciones Android (fragmentos, ciclo de vida, arquitectura cliente/servidor)

Una característica clave de este documento es la presentación de un **marco genérico de aplicaciones Android cliente/servidor**, que puede reutilizarse en numerosos proyectos.




---

## 🎯 Objetivos de aprendizaje

* Comprender los fundamentos del desarrollo de Android
* Dominar la navegación entre vistas y fragmentos
* Gestionar el ciclo de vida de los componentes de Android
* Implementar arquitecturas cliente/servidor
* Manipular datos a través de interfaces de usuario
* Introducir la programación asíncrona con RxJava
