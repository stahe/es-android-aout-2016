    4. Tarea 1: Gestión básica de nóminas

    4.1. Introducción

    Para aplicar lo que hemos visto anteriormente, proponemos ahora una tarea que consiste en el desarrollo de un cliente Android para tabletas, diseñado para simular los cálculos de nóminas de los empleados de una asociación.

    La aplicación tendrá una arquitectura cliente/servidor:

    • el servidor [1] ya está disponible;
    • tú debes crear el cliente Android [2].

    4.2. La base de datos

    4.2.1. Definición

    Los datos estáticos necesarios para generar la nómina se almacenarán en una base de datos a la que en adelante nos referiremos como «dbpam» ( ). Esta base de datos contiene las siguientes tablas:

    Tabla EMPLOYEES: contiene información sobre los distintos proveedores de servicios de guardería

    Estructura:

    ID
    clave primaria
    VERSIÓN
    número de versión: se incrementa con cada modificación de la fila
    SS
    Número de la Seguridad Social del empleado: único
    NOMBRE
    Apellido del empleado
    NOMBRE
    Nombre
    DIRECCIÓN
    su dirección
    ciudad
    su ciudad
    CÓDIGO POSTAL
    su código postal
    N.º DE INDEMNIZACIÓN
    Clave externa en el campo [ID] de la tabla [INDEMNITES]

    Su contenido podría ser el siguiente:

    Tabla COTISACIONES: contiene los porcentajes necesarios para calcular las cotizaciones a la Seguridad Social

    Estructura:

    ID
    clave primaria
    VERSIÓN
    número de versión: se incrementa con cada modificación de la fila
    CSGRDS
    Porcentaje: Contribución social general + Contribución al pago de la deuda social
    CSGD
    Porcentaje: contribución social general deducible
    SECU
    porcentaje: seguridad social, viudedad, vejez
    PENSION
    porcentaje: pensión complementaria + seguro de desempleo

    Su contenido podría ser el siguiente:

    Las tasas de cotización a la seguridad social son independientes del empleado. La tabla anterior solo tiene una fila.

    Tabla ALLOWANCES: contiene los elementos utilizados para calcular el salario a pagar.
    ID
    clave primaria
    VERSIÓN
    número de versión: se incrementa con cada modificación de la fila
    ÍNDICE
    Índice de procesamiento: único
    TARIFA HORARIA
    Precio neto en euros por una hora de guardia
    MANTENIMIENTO DIARIO
    Dietas diarias en euros por día de asistencia
    COMIDA AL DÍA
    Subsidio de comida en euros por día de asistencia
    PAGA DE VACACIONES
    Subsidio de vacaciones pagadas. Se trata de un porcentaje que se aplica al salario base.

    Su contenido podría ser el siguiente:

    Tenga en cuenta que las prestaciones pueden variar de un proveedor de cuidado infantil a otro. Están vinculadas a un proveedor de cuidado infantil específico a través de su categoría salarial. Por ejemplo, la Sra. Marie Jouveinal, que tiene una categoría salarial de 2 (tabla EMPLOYEES), tiene un salario por hora de 2,1 euros (tabla INDEMNITES).

    4.3. Servidor web / Instalación de JSON

    4.3.1. Instalación

    Se proporciona el binario Java para el servidor web/JSON:

     

    Para iniciar el servidor web/JSON, proceda de la siguiente manera:

    • Inicia el sistema de gestión de bases de datos MySQL;
    • asegúrese de que la base de datos [dbpam_hibernate] existe;
    • Abre una ventana de símbolo del sistema;
    • Vaya a la carpeta jar;
    • escriba el comando: 
    java -jar pam-server-01-all-1.0.jar

    Esto supone que el ejecutable [java.exe] se encuentra en la ruta PATH de su equipo. Si no es así, escriba la ruta completa a [java.exe], por ejemplo:

    D:\Programs\devjava\java\jdk1.8\bin\java -jar pam-server-01-all-1.0.jar

    4.4. Pruebas del cliente Android

    A continuación se proporciona el binario ejecutable del cliente Android finalizado:

      

    Utiliza el ratón para arrastrar el archivo [pam-client.apk] que aparece arriba hasta el emulador de tabletas [GenyMotion]. Se guardará y se ejecutará. Inicia también el servidor web/JSON si aún no lo has hecho. La finalidad del cliente Android es recuperar la información devuelta por el servidor web/JSON y darle formato. Las diferentes vistas del cliente Android son las siguientes:

    En primer lugar, debes conectarte al servicio web/JSON:

    • en [1], introduce la URL del servicio web/JSON. Con el emulador, introduce una de las direcciones IP del PC (pero no 127.0.0.1). Con una tableta, introduce la dirección Wi-Fi del equipo del servidor web/JSON y desactiva el cortafuegos del servidor si lo tiene, ya que podría bloquear las llamadas entrantes;
    • En [2], inicia sesión;

    A continuación, se le redirigirá a la página de simulación:

    • En [3], seleccione un empleado;
    • En [4], introduzca un número de horas;
    • En [5], introduzca el número de días;
    • En [6], ejecute la simulación;

    La página de simulación resultante es la siguiente:

    • en [7], los resultados de la simulación;
    • en [8], guárdelo;

    4.5. Tareas pendientes

    Se te proporciona el esqueleto del cliente Android presentado anteriormente. Se ha creado a partir del proyecto [client-android-skel] descrito en la sección 2.

    • ejecuta la versión completa para comprender el trabajo que hay que realizar;
    • ejecuta la versión ligera y estudia su código. Sigue los métodos de diseño utilizados en las páginas anteriores;
